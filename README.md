🎓 Scholarship Eligibility Test Using Python
📌 Project Overview

The Scholarship Eligibility Test is a Python-based project designed to determine whether a student is eligible for a scholarship based on predefined eligibility criteria.

The program takes student details and academic information as input and evaluates the student's eligibility according to the specified conditions.

This project demonstrates the use of Python fundamentals, conditional statements, user input, and logical operators.

🎯 Objectives
To automate the scholarship eligibility checking process.
To evaluate students based on predefined criteria.
To provide quick and accurate eligibility results.
To demonstrate the practical application of Python programming.
🛠️ Technologies Used
Programming Language: Python
Concepts Used:
Variables and Data Types
User Input (input())
Conditional Statements (if-elif-else)
Logical Operators
Basic Arithmetic Operations
⚙️ Features
Accepts student information.
Checks scholarship eligibility based on predefined conditions.
Displays whether the student is eligible or not eligible.
Simple and user-friendly execution.
Beginner-friendly Python implementation.
